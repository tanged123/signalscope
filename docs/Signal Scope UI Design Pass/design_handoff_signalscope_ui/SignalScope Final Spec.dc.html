LIGHTLight theme — token remap of the final system
Mapping rules
Same roles, inverted ground. Cold-neutral light grays: void #E3E6EB app ground, #F7F8FA panels/tree, #EFF1F4/#E7EAEE bars. Chrome stays fully achromatic; active state = #C9CFD8 fill + ink text. Structure, spacing, and every rule from F0 are unchanged.
Ink: fg-1 #1A1E26 · fg-2 #4A5160 · fg-3 #7A8290 · fg-4 #A7AEBB. Grid #E4E7EC; borders #C9CFD8/#AEB6C2.
Accent + series
Amber darkens to #C17500 (interaction-only role unchanged: cursor, focus inset at rgba(193,117,0,.55), Δ readouts, pinned run, ƒx, drop targets) — ≥3:1 on the light ground where the dark theme's #FFA226 fails.
Series = the prototype's validated light palette #2A78D6 #EB6834 #1BAF7A #EDA100 #E87BA4 #008300 #4A3AA7 #E34948 — darker, saturated hues that hold on white. Slot colors differ per theme by design; identity still never color alone.
Behavior
T toggles theme; the flag lives in the session and both palettes ship inside every HTML snapshot, so a recipient can flip themes offline.
Shadows soften to blue-gray (rgba(30,40,60,.15–.22)); overlay scrim rgba(240,242,245,.88). Status: connected #007A3D, error #C42B2B. Everything else inherits by token — implement light as a token swap, never per-component styles.

FINALSignalScope — final design package for implementation
Visual system
Ground: near-black. App on --surface-void, panels + tree on --surface-0, bars on --surface-1/2. Flat, 1px seams, radii ≤4px, no glows.
Chrome is achromatic — grays only, including active/toggle states (surface-4 + fg-1). Amber is interaction only: cursor, focus inset, Δ readouts, pinned emphasis, ƒx/derived, drop targets.
Type: Inter for UI; JetBrains Mono + tabular-nums for every number, signal path, readout. Values %.4f; units as separate dimmed tokens.
Series: 8 categorical slots (--series-1…8), dash classes beyond 8; identity never color alone. Colorblind validation pending — fallback: prototype palette. Status colors reserved.
Structure
One workspace — panel grid + named layout presets, no tabs. Tree left (search-first, favorites, live values, sources). Formula bar docked under grid. Status bar carries perf truth + hint strip + reserved FOLLOW slot.
Panels — always-visible mode pills T·XY·FFT·H; drag header to rearrange, seam handles to resize; focused = 1px amber inset.
Legend — split chips: click = toggle, ▾ = inspector popover (color slot, line style, quick transforms, use-as-X, remove). Hover chip = emphasize series.
Many series — folder → color family or envelope band; hover isolates, click pins (pinned run renders amber).
Axes + data display
Every plot owns complete axes — spine, outward ticks, numeric labels, full name + unit on x AND y. No naked plots, no shared/implied axes. Anatomy is invariant: 3D = three labeled spines; colorbar = an axis (assigned via c: chip) with full anatomy; colormap perceptually uniform + colorblind-safe.
Axis style is a per-panel option — axes: gutter · inline. Gutter (default) = F2; inline = labels on gridlines with translucent backing + full corner tags = F3. Identical information either way; flag serializes into sessions/snapshots.
Everything inspectable/exportable — datatips are numbered annotations with optional text, listed per panel, embedded in every export. Export dialog shows size budget before writing.
