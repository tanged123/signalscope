# Monte Carlo Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reproducible eight-run Monte Carlo CSV set that demonstrates ensemble and partial-member behavior.

**Architecture:** A dependency-free Node script generates the committed CSV files and checks reproducibility. A Rust ingest test verifies the product-level grouping behavior.

**Tech Stack:** Node.js, CSV, Rust.

## Global Constraints

- Generate exactly eight runs with 1,001 samples each.
- Use `time`, `command`, `response`, and `temperature`; omit `temperature` only from run 8.
- Keep generation deterministic and dependency-free.

---
