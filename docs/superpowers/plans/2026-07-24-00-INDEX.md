## Sequencing

```text
06 ──────────────────────────┐         (any time; tiny version.mjs overlap with 01)
01 ──> 02 ──> 04             ├──> merge
        └──> 03 ──> 05       ┘
```

- **01 first** — it moves the Rust files every other Rust plan touches.
- **02 and 03 can run in parallel** after 01 (03 regenerates protocol files;
  rebase + `pnpm codegen` resolves any overlap).
- **04 requires 02** (protocol `EnvelopeBin`, envelope transport).
- **05 Task 2 requires 03**; its other tasks are independent — a second
  implementer can start Tasks 1/3/4/5 immediately.
- **06 is independent** — hand it out on day one.

## Ground rules for every implementer

From `AGENTS.md` / `CLAUDE.md` (binding):

- Use `./scripts/` wrappers for everything; they enter the Nix dev shell
  themselves. `./scripts/dev.sh <cmd>` runs an arbitrary command in-shell.
- Read the relevant ADRs before touching protocol/architecture/data code;
  the plans amend ADRs 0002–0005 and 0007 and add 0008 — those amendments are
  part of the deliverable, not optional.
- Preserve: two-host `DataPlane`, versioned protocol/session schemas,
  tile-pyramid gap/extrema invariants, transactional ingest, self-contained
  no-network snapshots.
- Run the affected script plus `./scripts/ci.sh all` before handoff; stage
  only intentional files; lowercase imperative commit messages.
